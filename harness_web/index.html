这是什么？

FlowERP：要持续交付的电商 ERP（库存、订单、采购）。

Harness：研发自动化工作台——接需求、受控改代码、跑 Eval、留证据、老板终审。

OPC 定位：可选挑战——超级个体带着 Agent 员工干活。规格员 / 工程师 / 质检员是 Agent，不是多用户账号。不是大纲 L01～L16 通过标准；结业仍以 Eval / 具名人审 / 证据链为准。

职责分离：工程师改代码，质检员挑刺，只有老板能终审通过；Agent 不能 approve。

侧栏筛选：全部 / 进行中 / 待验收 / 终态。

死信：自动化耗尽后的终态。用「复制会话再试」并启用改代码继续。

顶部进度条：跟踪「这一次改 FlowERP」的流水线与值班员工。

过程页：事件账本（含 agent:* 员工 actor），用于复盘和答辩。
