# 工作台参考资料｜需要时按问题查阅

第一次接触 AI 或软件开发，先读[从“导出库存表”理解软件开发](从业务需求到上线：理解Spec与个人研发工作台.md)：看人怎样说清要求、请助手实现、检查结果并接受。不熟悉命令和文件位置时，按 [L00](../courses/L00/README.md)动手准备。下面的架构与专题在有了具体问题后查阅。


跟课从[学生学习入口](../README.md)进入，继续当前讲的讲义、手册与提交。这里供遇到具体问题时查阅；也供已经使用工作台的读者了解设计与日常操作。

## 想理解 FDE 与工作台设计

按“FDE 与工作台的关系 → 整体构思 → 具体设计 → 专题操作”阅读。先理解现场问题怎样推动能力建设，再沿四张解释图理解设计原因与架构关系，遇到实现问题再查具体设计。

1. [FDE 与工作台：一个库存问题的图解](FDE与个人AI研发工作台.md)：先沿八张少字故事图，看人怎样判断、交付并积累方法，再理解工作台为何随 FlowERP 交付一起改进。
2. [个人 AI 研发工作台：设计思路与整体架构](个人AI研发工作台.md)：理解为何以事项延续问题、模块如何协作、证据怎样绑定代码，以及交付怎样支持经验复用。
3. [工作台具体设计](工作台具体设计.md)：按需查阅模块、数据、执行与恢复细节，以及经验和流程的采用条件。
