# L16｜在新环境接手，并完成现场新需求

你做的软件，另一位同伴能按说明启动吗？启动后出现一项没预先练过的小需求，你还能说清、实现并检查吗？最后一讲把前十五讲的方法用于这次真实接手与新交付。

冷启动是按交接说明在新环境重新准备并启动；迁移是条件改变后仍能选择和运用学过的方法。今天要交出真实新实现，旧截图和启动成功只覆盖其中一部分。

库存查找怎样确认范围、设计反例，见[辅导资料的需求确认与检查](辅导资料.md#new-requirement)。本页提供阅读入口。

本讲沿用 [L11 的分工](../L11/README.md)、[L12 的等待与恢复](../L12/README.md)、[L13～L14 的服务与页面](../L13/README.md)及 [L15 的经验治理](../L15/README.md)。新难度是陌生环境、陌生使用者和未预演需求。

## 按这条路线学习

1. [辅导资料](辅导资料.md#final-practice)：先看四件亲手工作与全课程路线，再理解七步交付；最后回到[全课程总结](辅导资料.md#course-retrospective)。
2. [实践操作手册](实践操作手册.md#lesson-goals)：用已建能力完成双仓接手、新检查、新实现、返工、人审和交接。
3. [提交模板](SUBMISSION.md)：记录本次实战与个人全课程成果，准备五分钟答辩、技术债和下一事项迁移。

**本讲动作线：** 冻结两个仓库与环境 → 同伴独立冷启动 → 现场确认未实现需求 → 新检查先红 → 范围内实施后绿 → 具名复验 → 恢复、导出、反馈与答辩。
