# L10 主线自学版 imagegen 资产记录

生成方式：OpenAI 内置 imagegen。用途：16:9 课程 PPT 教学示意图。

共同视觉约束：暖白底、深海军蓝与石板蓝、低饱和琥珀色强调；平面编辑式半等距技术插画；不放入中文或品牌文字，不使用水印；预留可编辑 PPT 标注区域。

## 01-mainline-flow.png

提示词要点：展示一个 FlowERP 预占订单无法发货的现场；学生与 AI 开发伙伴调查；个人工作台组织验证、有界修复和证据；结果为恢复发货或安全交接。用一条连续左到右因果链表达，不做 UI 截图。

## 02-one-decision-round.png

提示词要点：用环形工作台表达一个完整修复决策轮：检查当前候选、读取证据、生成有界任务、AI 实现修复、保存 Diff 与执行记录、回到验证门。强调修改不等于通过，人可随时停止轨道。

## 03-four-decisions.png

提示词要点：一个候选到达中央证据门后分成四类明确出口：验证通过、无实质进展、轮数上限、时间或 Token 预算耗尽。每个出口都带证据文件夹，四条路径都是显式工程决策。

## 04-converge-vs-stop.png

提示词要点：对比同一 FlowERP 发货缺陷的两条轨迹。左侧：红灯、一次有界修复、独立复验绿。右侧：红灯、执行结束但无实质改善、再次红灯、完整证据交给人。不把执行成功画成产品成功。

## 05-budget-handoff.png

提示词要点：展示修复旅程消耗轮数、时间和 Token 三种资源；下一次修复开始前，人看到仪表并主动停止；将最后已验证候选、剩余失败、Diff 和下一步放入安全交接箱。不用金钱或赌博意象表示 Token。

## 06-loop-to-subagents.png

提示词要点：左侧用纵向的检查—修复—再检查表达 L10 Loop；右侧用多条独立并行工作道表达 L11 Subagents；两侧都经过个人工作台，由人设定边界并承担最终汇总责任。
