# L09 图与执行证据

diagrams 是判断流程与业务数量示意。latest 中 JSON 为本轮原始命令、退出、报告或完整状态。HTML/PNG 是从这些记录生成的中文排版截图，不是原生工作台页面。

- cancel-* 与 *-state：真实临时库六种取消实验。leak 只改临时数据，normal 不是产品修复。
- mapping-*：真实转换器处理明确合成的六类输入。
- failed-to-draft、no-blocking-repair、exit-contradiction：实际失败报告到草案、无阻断与退出矛盾三条路径。
- candidate-*：隔离服务代码注入、真实三项失败、映射草案、教师补充任务、单文件恢复和原检查通过。红灯、绿灯、Diff 与来源分别保留。
