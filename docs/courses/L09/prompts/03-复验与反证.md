# 独立复核修复结果

从原任务和报告开始，核对实际候选、运行命令、退出码、必需用例和修复 Diff。指出哪些是事实、哪些仍是假设。检查是否误用了参考实验或另一套服务的结果。

改变 OTHER 的预占数量，先给出独立期望，再复验 TARGET 取消。补查一次重复或非法取消后的完整状态。检查映射器对观察告警、缺字段和错误类型的处理，以及输出是否包含可执行验收命令和真实文件范围。

核对测试是否被删减、降级或改弱。报告审查建议、实际执行与未执行项，不生成同伴签名。没有足够证据时指出缺口，不把修复候选称为已接受。

区分三个成功：草案生成成功、候选复验通过、负责人接受。逐一指出材料支持哪一层。对照[参考红灯](../assets/latest/candidate-red.json)和[参考绿灯](../assets/latest/candidate-green.json)时，仅用它们理解方法，不归为本人的执行结果。
