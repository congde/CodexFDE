# L00｜课前准备：装好工具，跑通第一次环境自检

**L00 先完成环境准备。课程已提供工作台项目壳，从 0 搭建是参考选做。** 你可以接收现成壳，也可以另建一个新项目，与 Codex 一起设计和搭建；后续课程在选定的个人项目里逐步补功能。

通常按这条路径开始：**核验环境 → 接收现成壳 → 进入 L01 → 在同一项目继续建设。** Windows 使用 PowerShell，macOS 使用 zsh，每步只运行自己系统的命令。

## 按这个顺序使用资料

| 顺序 | 打开什么 | 完成标志 |
|---|---|---|
| 1. 准备环境 | [L00 实践手册](./L00｜课前准备：装好工具，跑通第一次环境自检.md) | 参考仓库的 `.venv` 可运行；Codex 引用的两个文件已由本人打开核对 |
| 2. 使用现成壳 | [L01 第 1.1 节：接收课程壳](../L01/实践操作手册.md#provided-shell) | 工具将课程壳放入个人空目录，位置与来源有记录 |
| 3. 继续建设 | [L01 实践手册](../L01/实践操作手册.md#prepare) | 在这个个人项目中形成需求、红灯测试，建设五个账本操作并复验 |

已经有个人工作台壳时，使用 [L01 的已有壳接续入口](../L01/实践操作手册.md#continue-shell)，保留原目录和实现。

## 参考选做：与 Codex 从 0 搭建

建议另外创建一个新的工作台项目，依据[从 0 搭建手册](./从0开始搭建个人AI研发工作台.md)，先看图理解架构，再确认设计、分步实现并亲自复验。完成后沿这个新项目进入 L01。

课程壳位于 [starter/](./starter/)，只有首页、健康检查和壳测试；任务与证据账能力从 L01 开始建设。现成壳和选做自建壳都采用与参考项目对应的目录结构，后续功能沿原位置增加。模板提供起点，个人的需求决定、实现与检查仍需在后续课程中完成。

终端执行命令，编辑器查看文件和写记录，Codex 对话框接收自然语言任务。遇到失败停在当前步骤，保留原错误，修复后重新检查。Codex 的完成声明不能替代你的现场操作。

环境结果保存到[环境记录模板](../labs/L00/SUBMISSION.md)约定的位置。选择从 0 搭建时，再保存自己的[搭建记录](./从0开始搭建个人AI研发工作台.md#run-records)；未选做者无需填写从零建设记录。

旧实验的代码、数据库和记录继续保留。进入 L01 时带上参考仓库与解释器路径、环境记录；已有个人项目时再带上其路径和实际检查记录。返回[课程总入口](../../README.md)。
