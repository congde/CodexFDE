Use case: infographic-diagram
为中文课程 L11 绘制一张易懂、清晰、专业的总结图，横向 16:9 高清白底教学信息图。读者刚接触多代理协作，需要一眼理解一个完整案例。现代扁平图形，深蓝标题，蓝色代表主任务，青绿与橙色代表两个并行子任务，留白充足，中文文字大且准确，无装饰性复杂背景、无机器人、无代码截图。
标题：“L11｜两个子代理，怎样一起把事情做对？”
副标题：“以采购申请为例：先分清任务，再并行，最后统一验收”
主体从左向右排列四个阶段，第二阶段内部必须上下两条并行支路，清晰箭头先分叉再汇合，不能画成甲完成后才到乙：
第一阶段 “① 明确目标”
正文：“申请采购 7 件商品”“申请保存成功，库存保持不变”
小标签：“主 Agent 固定同一份代码”
第二阶段 “② 两项工作同时做”
上方青绿框：“子代理甲：补测试”“编写检查，验证申请和库存”“只修改指定测试文件”
下方橙色框：“子代理乙：查风险”“阅读代码，寻找提前入库问题”“返回问题位置和依据”
两框下方共用浅底提示：“可以并行的前提：共同输入不变，互不改动对方依赖的内容”
第三阶段 “③ 主 Agent 汇总修复”
正文：“核对两份结果的依据”“复现发现的问题”“集中修改，再次检查”
第四阶段 “④ 统一验收”
正文：“申请正确保存”“库存仍未增加”“最终版本测试通过”
末行：“由人确认接受”
底部独立短条，三个简短规则横向排列，每条配简洁图标：
“文件不同，也可能互相影响”
“各自完成，还要整合检查”
“同时工作，不保证更省时间”
图中所有文字严格使用以上中文与 Agent 字样，不增加读写集、哈希、合同、证据链等术语，不虚构实际执行结果。图是方法总结，非运行记录。字体清晰，流程箭头不穿文字，四阶段宽度根据内容分配，第二阶段最宽。
