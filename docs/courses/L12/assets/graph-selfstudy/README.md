## 定向修订提示

04-state-handoff-v2：共享状态的“读取 X + R-X”箭头必须指向等待审核节点；当前节点值改为等待审核；移除右侧额外批准和拒绝分支。其余布局、数据写入关系与标签保持不变。

08-loop-subagents-graph-v3：Graph 列按开发、检查、等待审核、完成推进；检查通过才等待，有效批准才完成；打回且有预算才回开发。Loop 列中未通过且有预算直接进入修订，达标停止，另以文字说明无预算则停止并保留失败。不得从停止状态连回修订。Subagents 列保持两个独立任务汇入整合复验。
