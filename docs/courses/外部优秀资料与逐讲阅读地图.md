# 外部优秀资料与 16 讲阅读地图

> 目的：为每一讲提供“少而准”的一手资料，并明确怎样把资料变成课堂动作。本表不改变课程大纲，不以外部框架取代本仓库的可运行基线。

## 使用方法

教师备课时先读“主读”，只选与本讲认知冲突直接相关的段落；“辅读”用于解释工程边界。学生不需要课前读完全部链接，而是在完成首次判断后带着问题查证。外部图表只作为阅读对象，不复制进讲义；课堂使用本项目截图和原创图重建概念。

## 教学法资料：贯穿 16 讲而不是独立成一讲

- [HBS Case Method Teaching](https://www.hbs.edu/case-method-project/about/Pages/case-method-teaching.aspx)：案例只提供决策者当时拥有的信息，并停在未揭示答案的决定点；学生先站到主角位置作选择。
- [Cornell Problem-Based Learning](https://teaching.cornell.edu/teaching-resources/active-collaborative-learning/problem-based-learning)：真实问题先于相关知识，学生先界定问题、识别知识缺口、比较方案并报告结果。
- [CMU Active Learning](https://www.cmu.edu/teaching/resources/instructionalstrategies/activelearningstrategies/index.html)：用于“预测—观察—解释”、同伴讨论和低风险反馈。
- [CMU Flipped Learning](https://www.cmu.edu/teaching/technology/flippingtheclass/index.html)：线上负责问题框架和关键示范，线下负责故障、反证、修订和迁移。
- [CMU Course Alignment](https://www.cmu.edu/teaching/assessment/basics/alignment.html)：检查目标、活动、产物和评分是否指向同一个可观察能力。
- [CDIO Standards](https://cdio.org/implementing-cdio/standards/12-cdio-standards)：检查课程是否覆盖构思、设计、实现、运行，而不是停在工具演示。

## 资料可信度与更新规则

1. 优先级为：官方标准/官方文档/研究机构教学资源 → 权威工程手册 → 高质量二手解读。
2. 二手文章可以帮助教师理解，但不能作为产品语义、协议语义或安全边界的唯一依据。
3. 每条链接必须在正文附近写清“借鉴什么”；只有书目没有转化动作，视为无效引用。
4. Codex、Hooks、Subagents、API 和申报政策属于易变信息，开课前重新核对。
5. 核对记录只证明资料已阅读，不证明课程已产生真实教学效果。
