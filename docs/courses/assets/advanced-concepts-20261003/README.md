## 怎样保留与复用配图

图片与消费它的讲义一起保留目录结构，不能只复制 Markdown 而遗漏图片。课程分发保留正式配图和教学说明，图片生成提示词、临时清单和中间草稿不随课程提交。

图 01 移除了初稿虚构的命令、业务状态和署名；图 04 修正了业务幂等键与候选身份的混淆；图 06 修正了绕过主 Agent 集成的箭头。其余图逐张核对文字、流向和责任边界后保留。L13～L16 仍遵守仓库的本地待发布规则，这组共享图不授权发布对应讲义。

## 内容依据与核验范围

以下链接用于维护者核对易变机制。核验日期为 2026-10-03；学生先读正文，不需要先阅读外部资料。课程中的具体案例、命令和实现边界以仓库源码及各讲材料为准。

- [OpenAI 官方 AGENTS.md 文档](https://learn.chatgpt.com/docs/agent-configuration/agents-md)：持久项目指令与目录范围，为 L02 的规则职责说明提供依据。
- [OpenAI 官方 Skill 文档](https://learn.chatgpt.com/docs/build-skills)：将流程指令、资源与可选脚本封装成能力，并按需要读取，为 L02、L15 的流程封装说明提供依据。
- [OpenAI 官方 Subagents 文档](https://learn.chatgpt.com/docs/agent-configuration/subagents)：分派任务与管理子 Agent，为 L11 的协作机制提供外部对照；课程分工及冲突判据仍由本讲合同定义。
- [OpenAI 官方 Eval 最佳实践](https://developers.openai.com/api/docs/guides/evaluation-best-practices)：针对任务设计评测、保留真实失败并持续复验，为反例与独立评价提供外部对照；本课程使用标准库与自己的业务 Eval。
- [Cosmic Ray 官方概念文档](https://cosmic-ray.readthedocs.io/en/latest/concepts.html)：修改实现、以固定测试检验辨识力，为 L05 的变异测试思想提供概念依据；课程没有安装或要求这一工具。
- [工作台闭环建设规格](../../../architecture/工作台范式与闭环建设.md)：核对 Harness、记忆与工作流蒸馏的建设要求、当前实现和真实项目证据缺口。

实际实现可沿正文进入 `workbench/execution.py`、`workbench/initiative_workflow.py`、`workbench/learning.py`、`workbench/workflow_graph.py`、`eval/report_contract.py` 及逐讲实验源码。配图帮助建立判断关系，不扩大它们已经验证的能力范围。
