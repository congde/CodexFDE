+Use case: scientific-educational

Primary request: 准确表现“建设并实际使用个人工作台 → 现场判断 → 受控交付 → 能力复用”，说明每一步做什么、留下什么产物，以及反馈怎样推动工作台改进。核心主题是“工作台 + FDE，用于解决学员熟悉项目中的真实问题”。
Style/medium: 现代教材插画与清晰流程图相结合，白底、深蓝标题，四个阶段用蓝、青、绿、橙柔和区分，人物和电脑使用精致的小型三维插画，专业亲切。大字号、清晰的中文黑体，留白充足，与已有“工作台 + FDE”行动营回顾图协调。文字及箭头比装饰更重要。
Composition/framing:
上方大标题“毕设实践流程”，副标题“工作台 + FDE 解决真实问题”。
中部四张从左到右同尺寸的大卡片，四步编号“1”“2”“3”“4”明显且顺序准确，之间三个明确向右的粗箭头。每张卡片上半部分放标题和动作，中央放一个小插画，下半部分放两行以内的产物说明。确保每个字在正常阅读尺寸可读，不要把长句压缩成小字。
