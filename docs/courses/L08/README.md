# L08｜把同一套 Eval 接入 CI

自己电脑上检查通过，别人怎样确认交出的那一版也通过了？本讲让仓库平台运行原检查、保存报告；同时修复订单留货失败后留下半份记录的问题。

由仓库平台在另一环境执行约定检查的流程，叫 CI。整单原子预占表示全部商品都够才一起留货；其中一行不够，本次留货全部不生效。

客户产品继续实现整单原子预占：所有商品一起留货，一行失败就不留部分预占。业务有错而 CI 假绿时，先修失败传递得到 B 可信红，再只修业务得到 C 可信绿。

![A 假绿、B 可信红、C 可信绿分别改变什么](assets/reading-figures-v2/key-example.png)

先看图中每次改了哪一层，再看颜色。完成后留下同入口工作流、三次真实远程运行和原始报告；L09 用报告中的失败形成下一份可授权修复任务。

按这条顺序完成，不需要先浏览所有附件：

1. [辅导资料](辅导资料.md)：理解本次现场问题、要求和判断依据。
2. [实践操作手册](实践操作手册.md)：准备个人候选，拆回课程与独立 FlowERP 两仓，固定远程产品版本，再完成 A 假绿、B 可信红、C 可信绿；目标、合同及 Codex 提示词都在对应步骤内。
3. [SUBMISSION：个人证据索引](SUBMISSION.md)：从首次判断开始关联已有记录，提交实际失败、Diff、复验与具名决定；未做项如实标待完成。
