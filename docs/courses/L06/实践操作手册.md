本次分两次修：先让总结如实报告错误，再让库存导出正确。Harness 是组织检查并汇总结果的程序。每次只改这一阶段允许的文件，再运行原检查，才能判断修改是否有效。

在同一个窗口定义下面的调用函数。它会核对真实退出码，报告和命令回执保存在候选外，已有报告不能覆盖。

后续调用的第三个参数是**预期退出码**，不是要强制写入的结果。例如 `run '04-business-block' 1` 要求真实业务命令退出 1；实际值不符，函数就停止。`contract` 查运行器，`run` 查业务，`review` 查报告，先认清当前命令检查哪个对象。

**Windows（PowerShell）：**

```powershell
function Invoke-L06Stock {
    param([string]$Action, [string]$Name, [int]$Expected, [int]$Opening=8, [int]$Reserved=3)
    $report = Join-Path $reports ($Name + '.json')
    $arguments = @('-B','-X','utf8',$tool,$Action,'--session',$session,'--report',$report)
    if ($Action -eq 'run') { $arguments += @('--opening',"$Opening",'--reserved',"$Reserved") }
    & $python @arguments
    $actual = $LASTEXITCODE
    if ($actual -ne $Expected) { throw "预期退出 $Expected，实际 $actual；先查本次回执" }
}
```

**macOS（zsh）：**

```zsh
invoke_l06_stock() {
  local action="$1" name="$2" expected="$3" opening="${4:-8}" reserved="${5:-3}"
  local report="$reports/$name.json" actual
  local -a arguments
  arguments=(-B -X utf8 "$tool" "$action" --session "$session" --report "$report")
  if [ "$action" = run ]; then
    arguments+=(--opening "$opening" --reserved "$reserved")
  fi
  if "$python" "${arguments[@]}"; then actual=0; else actual=$?; fi
  if [ "$actual" -ne "$expected" ]; then
    printf '预期退出 %s，实际 %s；先查本次回执。\n' "$expected" "$actual"
    return 1
  fi
}
```
