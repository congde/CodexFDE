# 每节课文件夹总览

本目录 `lessons/` 按课程大纲为每一讲建立独立文件夹，统一使用 `_template` 模板结构。下表给出每个文件夹与大纲节次的对应关系。

## 文件夹结构

```text
lessons/
├── _template/                  # 模板（复制用）
├── lesson-00-opening/          # 开篇词
├── lesson-00-guide/            # 导读
├── lesson-01 ~ lesson-16/      # 16 节正课
└── lesson-16-closing/          # 结束语
```

每个 `lesson-XX` 内部均为统一模板：

```text
lesson-XX/
├── 01-video/                   # 视频 + 脚本 + 字幕
├── 02-slides/                  # 课件
├── 03-code/                    # 配套源码
├── 04-assignment/              # 作业 + 参考答案
└── 05-assets/                  # 素材
```

## 按周交付物目录（week-XX）

除按"节"组织的 `lesson-XX` 外，另设按"周"组织的交付物目录 `week-XX`，用于归集每周产出的**交付物**（代码、文档、Skills、AGENTS 配置、Eval harness、部署配置等），方便运营与学员打包带走。

| 周 | 主线迭代 | 独立项目 | 交付物目录 |
|---|---|---|---|
| 第一周 | V0 单 Agent 最小交付骨架 | 智能文档生成器 | `week-01/` |
| 第二周 | V1 全自动无人值守流水线 | Git 提交质量门禁 | `week-02/` |
| 第三周 | V2 多 Agent 协作闭环 | 遗留代码现代化重构助手 | `week-03/` |
| 第四周 | V3 可对外交付的 AI 开发工具 | 个人 AI 工程作品集门户 | `week-04/` |

每个 `week-XX` 内部使用统一交付物分类子目录（按周按需取舍）：

```text
week-XX/
├── README.md          # 本周交付物清单与目录说明
├── 01-code/           # 源码交付物（主线 + 独立项目）
├── 02-docs/           # 文档交付物（SPEC、README、教程）
├── 03-skills/         # 封装的 Codex Skills
├── 04-agents/         # AGENTS.md / AGENTS.yaml 智能体配置
├── 05-harness/        # Eval 评估测试库 / 反馈采集飞轮
├── 06-cicd/           # CI/CD 定时任务配置（第二周）
└── 06-deploy/         # 云端部署配置（第四周）
```

## 使用建议

1. 建课时复制 `_template` 到对应 `lesson-XX`，再按需增删子目录。
2. 每周交付物归入对应 `week-XX`，在 `week-XX/README.md` 的交付物清单表中登记类型、位置与说明。
3. 每节课在 `03-code/README.md` 写明运行依赖与命令，保证可复现。
4. 目录命名与大纲节次严格对应，便于后续自动化生成栏目页或播放列表。
