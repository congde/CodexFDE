## tag: opening

- **讲次**：开篇词
- **标题**：AI 能写代码，但不能替你承担工程责任
- **一句话内容**：建立全行动营最重要的边界——Codex 帮你编码、自测、重构，FDE 帮你构建自优化飞轮，但代码质量、安全合规与交付责任始终由你承担。
- **核心观点**：对高薪一线程序员而言这叫**身价来源**：价值不在"会调用 AI"，而在"能对 AI 的产出负责、敢让它放手干"，这是与"只会聊天式用 AI"的人的分水岭。
- **交付物**：无（认知建立）。

---

## tag: guide

- **讲次**：导读
- **标题**：从对话写代码到 FDE 工程化：先看一套能跑起来的完整成品
- **一句话内容**：先用 15 分钟完整演示行动营最终成品——一套已上线、能自动接需求、自动写代码、自动 Eval 质检、多 Agent 协作、云端持续运营的**个人 AI 开发流水线**。
- **核心观点**：让学员在动手前就"看见 4 周后的自己"，建立学习定锚；随后给出全营知识地图与 4 周学习路线。
- **交付物**：全营知识地图、4 周学习路线。

## tag: closing

- **讲次**：结束语
- **标题**：真正的过关，是下一次需求也知道怎么委托
- **一句话内容**：行动营目标不是记住 Codex 的每个功能按钮，而是建立一条可复用工程链路：接到需求 → 写 SPEC → 委托 Codex → 自动质检 → 多 Agent 协作 → 服务化部署 → 持续运营飞轮。
- **核心观点**：真正的过关，是下一次拿到真实需求时，第一反应是写 SPEC、定验收、选 Agent、配流水线，而不是打开聊天框随口问一句。
- **交付物**：结业交付（4 个独立迷你项目 + 1 套主线流水线，组成个人 AI 工程作品集）。
