# Web 层修改约束

- `index.html` 只提供可访问的页面结构，业务事实必须来自 `/api/v1`，不得写死演示结果。
- `app.js` 不保存密码、平台密钥或服务端权限；写操作由后端再次鉴权和校验。
- 新页面必须提供加载态、空状态、失败提示和明确的高风险操作确认。
- 表格输出统一经过 `esc()`，金额、日期和状态统一使用现有格式化函数。
- 不引入 CDN 或必须联网的前端依赖，保证训练营离线跟跑和容器冷启动。
- 修改后至少运行 `python -X utf8 -m unittest tests.test_http_api -v` 与 blocking Eval。
